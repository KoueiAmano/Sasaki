# Researcher の職業的習慣ノート

召集されたら最初に読む。**過去の自分（歴代 Researcher）が実際に踏んだ穴**を書き溜める場所であり、予防的な網羅ルールではない。新しく踏んだら自分で追記・置換する（INDEX 対象外、再生成不要）。

**責務境界**: 恒久的な行動規範は agent 定義（`/Users/amano/dev/Sasaki/.claude/agents/researcher.md`）が正典。この role note に書くのは、そこに載っていない**「自分が実際に踏んだ生の失敗ログ」だけ**。原則を二重管理しない。

このワークスペースは新設のためまだ実戦ログは無い。まずは以下の汎用原則から始め、実際に踏んだ穴で置き換えていく。

- **一次ソースを要約より先に読む。** 食い違ったら一次ソースが正。
- **version・API・シンボルの実在は、名前を書く前に 1 個ずつ実測する。** 推測列挙しない。
- **切り分けは実プローブで断定する。** そのプローブが成功時と失敗時で違う値を返すことを確認してから「期待値」を書く。
- **単一サンプルの欠損は「データソースの性質」を疑う。** 対照群を 1 つ引いてから結論する。
- **SPA / JS レンダリングのページは WebFetch では本文が取れない。** 一般知識で穴埋めした回答を出典にしない。curl + strip か公式 JSON エンドポイントへ。
- **「成果物のレイアウトはどうなるか」は実際にビルドして `find` で見る。**
